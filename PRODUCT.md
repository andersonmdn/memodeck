# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Started as the developer's personal tool; evolving toward a broader audience of Portuguese-speaking learners (pt-BR) who are comfortable editing Markdown. Primary usage context: self-directed study sessions — vocabulary, programming concepts, factual recall — using files they author locally or generate with an AI assistant.

## Product Purpose

MemoDeck is an offline-first PWA for spaced-repetition flashcards using the cloze deletion technique. It exists so learners can study effectively without surrendering their data to a cloud service or creating an account. Success means a user can build a deck, study it daily, and track their retention — entirely on their own device, indefinitely.

## Positioning

No account. No server. No tracking. Decks are plain `.deck.md` text files — readable, versionable, and AI-generatable — that never leave the user's machine. That combination is what Anki (heavy desktop client, proprietary sync) and Quizlet (cloud-required, account-gated) cannot truthfully copy at once.

## Operating Context

- Users import `.deck.md` files (drag-and-drop or file picker) from their filesystem or from AI-generated output
- An in-app AI Prompt page provides a copy-ready system prompt for generating decks with any LLM
- Study sessions are triggered daily; a streak counter and retention stats reinforce the habit
- Data backup and restore live in Settings; no external dependency

## Capabilities and Constraints

- **Cloze deletion format**: `{{cN::text}}` in Markdown paragraphs; each unique index per paragraph = one card
- **Spaced repetition**: custom algorithm (not SM-2); 4-point rating scale (Forgot / Hard / Good / Easy)
- **Persistence**: IndexedDB via Dexie; no server, no sync
- **PWA**: installable on desktop and mobile; works fully offline after first load
- **No backend — ever**: architecture principle, not temporary state
- **Language**: Portuguese (pt-BR) throughout; no internationalization planned
- **Dark theme**: currently dark-only; light mode not a committed constraint

## Brand Commitments

## Evidence on Hand

- Parser test suite covering cloze extraction edge cases

## Product Principles

1. **Yours, forever** — data lives on the user's device; no vendor lock-in, no account deletion risk.
2. **Frictionless creation** — the `.deck.md` format is designed to be written by hand or generated by an LLM in one prompt.
3. **Habit over features** — streak, retention rate, and daily due-cards are the core loop; complexity defers to consistency.
4. **No surprises** — offline-first means the app works identically whether or not there is a network connection.
5. **Grow naturally** — started personal, built to scale to a community of Markdown-native learners without changing the architecture.
